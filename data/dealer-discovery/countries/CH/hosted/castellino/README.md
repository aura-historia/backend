# Castellino Fine Arts hosted catalogue

Swiss ownership is limited to `https://www.anticstore.com/antiquaire/castellino-fine-arts` and its corresponding English merchant namespace. Anticstore and other merchants are not this operator. The current legal operator is Castellino Fine Arts Sàrl, Geneva. Ingestion remains empty.

This nested ledger has its own explicit audit, index and verification paths. Country totals and the combined CH index include these resources; `../../country-verification.json` records root and hosted readback coverage. Public pages, identity snapshots and country-local orchestration are external under `/tmp/aura-dealer-discovery/CH/`.
